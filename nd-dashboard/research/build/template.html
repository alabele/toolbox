    Claude Code already does part of this

    Claude Code 2.1.278 ships a multi-session view that sorts sessions by what needs you. It lets you answer a session's question in place, and it posts a recap when you reattach. There is also a machine-readable version.

    claude agents          # the built-in view
claude agents --json   # live sessions with state and folder, no terminal needed

    When I ran it, it listed four live sessions. One was a background session in global-sdlc that had been blocked for about three months. That is exactly the kind of thing this dashboard should surface gently.

    Lifecycle hooks can also push events from every repo to one place. They distinguish "waiting on permission" from "finished and idle". You already have one hook configured, so new ones go alongside it.

    So do not rebuild the session list. Build what it lacks: a trustworthy quiet state, intensity controls, release at boundaries, and merging with Jira, GitHub, and Slack.

    Where to be careful

    Overturned, contested, and worth testing on yourself

    Popular ideas the evidence did not support

    • “More options is always worse.” The average effect is near zero.
    • “Decision fatigue” as a draining willpower budget. It did not replicate across 36 labs.
    • Unfinished tasks staying in mind better. They do not.
    • “Gifted means perfectionist.” Not in the studies checked.
    • Dyslexia fonts, nature photos for attention, and “autistic people dislike yellow.”
    • Polyvagal theory is openly disputed. “Rejection sensitive dysphoria” is an unvalidated popular term.

    What I changed my mind about

    • I first said to show at most three items. The choice research does not support a fixed cap, so it is now a setting.
    • I first said to show how long your own tasks have been stuck. That feeds self-criticism. Age now shows only for agent sessions.
    • I first said to sort messages by who is waiting on you. The order can stay. A visible tally of people waiting should not.

    Experiments only you can run

    • Is a blocked agent worth interrupting you for, or should it wait in the queue?
    • What cap on things in progress helps, and does any cap trigger demand avoidance?
    • Does seeing agents work beside you act as a body double? Track time to start and a one-tap overwhelm rating, two weeks each way.
    • Light or dark? Legibility favors light. Your comfort was never studied.

    Keep one limit in mind. Nearly every study used neurotypical people, children, or students. No checked source studied the exact profile this tool is built for. The findings are the best available starting defaults, and your own reaction outranks them.
