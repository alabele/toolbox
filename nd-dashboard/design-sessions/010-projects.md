# 010 — Projects

**Asked:** "Organize these waiting-on items (and live sessions) by project or to-do. A bird's-eye view of everything I have in flight for Release 15.1.0 or LetsO bugs, and turn on/off high-priority versus low-priority projects."

## Decided

- A project is hers: a name, a priority (High, Med, Low), an on/off switch, and rules. Rules are ticket keys and words that match a title.
- Sessions, pull requests and waits sort in by rule. Anything she sorts by hand is remembered by its id, and its ticket key teaches the project.
- The Projects screen: the switches on top, then each project with everything in flight and how many need her, then Unsorted with buttons to sort.
- A project that is off leaves the sidebar and Rounds. Its section shows only "off, 3 in flight".
- Project priority comes before her own High/Med/Low in Rounds order, which comes before Pinned order.
