# 012 — Work from a project

**Asked:** "I would like to be able to work from the Projects view directly, and add a session directly within the project view itself."

**Roundtable:** interaction designer, executive-function coach.

## Decided

- **Rows open in place.** In the open project plate, a session or PR row opens where it sits, with the same content as an open Rounds plate: what it needs, the reply, one reply box, More. One row open at a time. Waits stay links.
- **Next here.** The open plate leads with one line: "Next here: VDC-2301, your turn." Click it and that row opens with the cursor in the box. Rounds picks the project; the project picks the next step.
- **New session in the project.** A button in the plate's foot opens a small form: Folder (the project's last folder, with its others to pick), Ticket, First message. Enter starts it; she stays on Projects; the session lands under In flight and belongs to the project by id. A ticket key teaches the project.
- **Guardrails.** Three or more sessions already going in the project: one line, "3 already going here." Never a block. Items that need her in other projects: one line at the foot, "Elsewhere: 4 need you. Open Rounds." When the project has nothing for her: "Nothing here needs you. Rounds has 3."
- **No Next one inside a project.** After Send, the row folds to Sent and stays.
